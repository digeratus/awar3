# AWAR3 launch site — Boundary Conditions

This is the recommended public launch version.

## Current configuration

This package is already set to:

- company name: `AWAR3`
- contact email: `info@awar3.com`

If you ever want to change those values later, edit `site-config.js`.

## Deploy to Cloudflare Pages

This is a static site with no build step. Upload the contents of this folder directly to Cloudflare Pages, or push it to a Git repository and create a Pages project from that repository.
